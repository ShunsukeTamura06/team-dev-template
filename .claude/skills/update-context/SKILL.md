# 業務文脈(README)の作成・更新

目的: 次にこのリポジトリを保守する人(とそのClaude Code)が、コードだけでは分からない業務の文脈を得られるようにする。

1. コードを読み、次をREADMEに下書きする(コードから読み取れる範囲)
   - 入力: ファイル/シート/列、置き場所(設定値名)
   - 出力: 形式と置き場所
   - 環境変数: `app/config.py` と `.env.example` から
   - 処理の流れ: 3〜7行の箇条書き
   - 用語集: コード上の名前と、推測される業務用語
2. コードから分からない項目は推測で埋めず、ユーザーにまとめて質問する。最低限、次を聞く
   - このツールが必要になった業務上の理由と依頼元
   - 主要な判定ルール・閾値の根拠(規程・慣行・依頼者の指示など)
   - 誰が・いつ使うか
   - 過去に起きた障害や、気をつけるべき点
3. 回答をREADMEに反映する。既存の記述は消さず、古くなった部分だけ更新する
4. 変更点をユーザーに要約して見せる
