# 各自の PC の初期設定

何度実行してもよい(すでに済んでいる項目は「すでに有効です」等と表示されるだけ)。

1. 次を実行し、出力をそのままユーザーに見せる

   ```
   python "${CLAUDE_PLUGIN_ROOT}/scripts/setup_pc.py"
   ```

   - `[NG]` が出たら、その内容と対処をユーザーに伝えて止める
   - pip が社内プロキシ等で失敗した場合は、社内の pip の設定(`pip config list`)を確認するよう伝える

2. 個人用の `~/.claude/CLAUDE.md`(Windows では `%USERPROFILE%\.claude\CLAUDE.md`)があれば読み、次の3つに仕分けた表をユーザーに見せる。**ユーザーが了承するまでファイルを変更しない**
   - チーム共通ルールと重複している行 → 削除を提案(チーム共通ルールはプラグインが毎回読み込むため)
   - チーム共通ルールと矛盾している行 → どちらにするかユーザーに確認。チーム全体で変えるべきなら、チーフに相談するよう伝える
   - 個人の好み(口調・説明の詳しさ・使うエディタなど) → 残す

3. 最後に、次をユーザーに伝える
   - 設定の反映には Claude Code の再起動(または `/reload-plugins`)が必要
   - 以後、チーム標準の変更は自動で届く(Claude Code の起動後しばらくして取り込まれ、次の起動から有効)
