# 新しいツールをひな形から作る

ひな形は `${CLAUDE_PLUGIN_ROOT}/templates/tool/` にある。

1. 現在のフォルダが Git リポジトリで、`main` ブランチにいることを確認する。違う場合は、社内 GitLab で空のプロジェクトを作って clone するようユーザーに伝えて止める
2. ひな形の中身(`.` で始まるファイル・フォルダを含む)を、現在のフォルダにコピーする。同じ名前のファイルがすでにある場合は上書きせず、ユーザーに確認する
3. ユーザーに次を質問し、README の(  )を埋める
   - ツール名と目的
   - 依頼元・利用者・利用タイミング
   - 入力と出力(ファイル・シート・列、置き場所)
   - 重要な判定ルールとその根拠
4. README を埋めたら、README 冒頭の「この README は、各ツールの README のひな形です」の囲みを削除する
5. `app/` と `tests/` のサンプル(閾値以上の明細を抽出する処理)を、ユーザーの説明に沿った処理に置き換えるかを確認し、置き換える場合はチーム共通ルールの構成に沿って実装する
6. `python -m pytest -q` を実行して通ることを確認する
7. 最後に、次をユーザーに伝える
   - 変更を commit して `main` に push する(最初の push だけは、保護設定の前なので直接 push できる)
   - 推進担当に、このプロジェクトの main ブランチ保護を依頼する(運用手順書「新しいツールを作る」)
